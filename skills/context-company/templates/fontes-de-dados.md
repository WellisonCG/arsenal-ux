# Fontes de dados

> Este é o arquivo mais importante para a fase 2 (Investigar). Com ele, o sênior sabe o que dá para puxar sozinho, o que precisa pedir e o que não existe.

| Fonte | Tipo | O que contém | Como acessar | Granularidade e período | Limites conhecidos |
|---|---|---|---|---|---|
| <ex.: Amplitude> | analytics de produto | eventos de uso (<lista dos principais>) | <MCP / API / dashboard / pedir para X> | por usuário e evento · desde <data> | <ex.: evento X com bug entre mar–abr> |
| <ex.: Zendesk> | suporte | tickets com tags | <…> | por ticket | <tags inconsistentes antes de…> |
| <ex.: Data warehouse> | dados de negócio | <tabelas principais> | <…> | <…> | <…> |
| <ex.: Repositório de pesquisa> | qualitativo | entrevistas e testes anteriores | <…> | por estudo | <…> |
