# Qual gráfico usar

Comece pela pergunta, não pelo gráfico.

**Origem do conteúdo:**
- **Da pós** `[pós: M5]`: linha, área, barras, pizza/donut, dispersão e small multiples.
- **Do pacote** `[prática]`: funil, histograma/box plot e as "Regras rápidas".

| Pergunta | Gráfico | Evite |
|---|---|---|
| Como um valor mudou ao longo do tempo? | **Linha**, que acompanha várias variáveis ao mesmo tempo | pizza |
| Como as partes de um todo mudaram no tempo? | **Área empilhada** (100% para proporção) | linha comum |
| Qual categoria é maior? | **Barras**, horizontais se os rótulos forem longos | pizza com mais de 5 fatias |
| Como se divide um todo, num único momento? | **Barras** ou, com no máximo 3 a 4 partes que somam 100%, **pizza/donut** | pizza para série temporal |
| Onde as pessoas abandonam? | **Funil**, ou barras por etapa com a % de passagem | — |
| Duas variáveis se relacionam? | **Dispersão** | linha |
| Comparar o mesmo gráfico entre vários segmentos? | **Small multiples**: vários gráficos pequenos na mesma escala | um gráfico com 10 séries |
| Como se distribui um valor (tempo de tarefa, ticket)? | **Histograma** ou box plot | média sozinha |

## Regras rápidas
- **Um gráfico, uma mensagem.** O título diz a conclusão. Exemplo: "62% param na segmentação", e não "Funil de campanha".
- **Mostre o n e a fonte** no rodapé: `[fonte: … · período] · n = …`.
- **Eixo de barras começa no zero.** Eixo de linha pode não começar, mas avise.
- **Destaque só o que importa.** O resto fica neutro.
